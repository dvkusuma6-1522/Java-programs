# Java Programming Practice

A collection of Java programs created to practice problem-solving, strengthen programming fundamentals, and prepare for technical interviews and placement coding rounds.

## About This Repository

This repository contains Java solutions to 20 medium-level programming questions covering arrays, strings, and number-based problems. Each program is maintained in a separate `.java` file for easy understanding, practice, and revision.

## Topics Covered

### 1. Array Programs
- Second Largest Element in an Array
- Find Duplicate Elements
- Remove Duplicate Elements
- Frequency of Array Elements
- Find Missing Number
- Move All Zeros to the End
- Rotate an Array by K Positions
- Maximum Subarray Sum (Kadane's Algorithm)
- Find Pairs with a Given Sum
- Merge Two Sorted Arrays

### 2. String Programs
- Check Whether Two Strings Are Anagrams
- First Non-Repeating Character
- Remove Duplicate Characters from a String
- Find the Longest Word in a Sentence
- Reverse Words in a Sentence
- Count Vowels, Consonants, Digits, and Special Characters

### 3. Number Programs
- Palindrome Number Without String Conversion
- Armstrong Numbers in a Range
- Prime Numbers in a Range
- Decimal to Binary Without Built-in Conversion Methods

## Technologies Used

- **Language:** Java

## How to Run the Programs

1. Clone or download this repository.
2. Make sure Java JDK is installed on your system.
3. Open a terminal in the folder containing the Java file.
4. Compile the required program:

   ```bash
   javac SecondLargest.java
   ```

5. Run the compiled program:

   ```bash
   java SecondLargest
   ```

Replace `SecondLargest` with the class name of the program you want to execute.
